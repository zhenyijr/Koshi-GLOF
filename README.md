# Koshi GLOF ArcGIS Project

ArcGIS Pro project data for Koshi Glacial Lake Outburst Flood analysis.

## Contents

- `arcgis-project/`: ArcGIS Pro project, project geodatabase, toolbox, and local project layers.
- `data/`: external datasets referenced by the project.

Large GIS files are tracked with Git LFS. Source datasets remain subject to their original licenses and attribution requirements.
